# Task blueprint

One file per task: `Tasks/<task_name>.md`

```markdown
# <Task name>

## Goal

One sentence: what is true once the task is done.

## Plan

The approach in a few lines: the why and the how.

## Steps

- [x] A finished step
- [ ] The next step
- [ ] A later step
```

## Rules

- A step is one action with a visible result.
- The steps are the status. There is no separate status field.
- The next step is always the first open box.
- If the plan changes, rewrite the plan and the steps. No history.
