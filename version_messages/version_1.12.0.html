🌟 Imaginer 1.12 — Two new models

OpenAI released the next generation of image models, and Imaginer supports both from day one. Each one generates and edits images, with and without masks.

Now powered by
Flare
gpt-image-2.5-flare
Fast. Good results for most prompts.
New default
Sunburst
gpt-image-2.5-sunburst
Highest precision for edits and demanding results. Takes longer.
Your current model selection is unchanged. Pick gpt-image-2.5-flare in the model dropdown to use the new default. The ℹ️ button next to the dropdown opens Choosing a Model in the manual.
  • 🔬Extra high and Maximum quality — two new levels in Config → Generation → Image quality, available for the gpt-image-2.5 models. Other models use High.
  • 👀Live previews for edits — partial previews now also appear while an edit is in progress.
  • 🏷️Edited images keep your prompt — prompt embedding and metadata stripping now apply to edit results as well.
  • 🙈Clearer moderation messages — when OpenAI provides details, the dialog names whether the input or the output was blocked and lists the categories.
  • 📐Full 4K — 3840×2160 is accepted as a custom size in the advanced size setting.
OpenAI removes older models from the API:
  • gpt-image-1 on 2026-10-23.
  • gpt-image-1.5, gpt-image-1-mini and chatgpt-image-latest on 2026-12-01.
If one of these is your selected model, switch to Flare or Sunburst before that date.
