🛡️ Imaginer 1.8 — Clearer when something goes wrong

When a generation can't finish, Imaginer now lets you know instead of leaving you watching the timer.

  • 🙈🤷🔄
    If you see this, it means that the moderation system has blocked the prompt. This can happen if the model thinks that the prompt contains content that violates the usage policies. In this case, the generation will stop immediately. You can then edit your prompt to make it compliant and try again.
  • 🧯No more endless spinners — a failed generation stops cleanly and its placeholder turns red, ready to retry.
  • 📐That dialog now scales to fit any window, so its Close button is always within reach.
Fewer mysteries, more making. ✨
